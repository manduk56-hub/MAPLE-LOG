## 수익 집계

일별 수익은 선택한 날짜, 날짜를 선택하지 않았을 때는 오늘을 기준으로 한다.
주간 수익은 같은 기준 날짜가 속한 목요일~수요일의 전체 기록을 집계하며 월과 연도 경계도 포함한다.
기본 집계는 기록별 분배 후 내 몫이며, 화면에서 아이템 총액으로 전환할 수 있다.
내 몫의 나머지 메소는 기록별로 버린다.
금액 합계는 BigInt로 계산하고 조·억·만·나머지 메소까지 표시한다.
보스 수 아이콘은 사용자가 제공한 원본 PNG를 그대로 보관하고 CSS로 투명 여백을 잘라 중앙에 배치한다.
월별 수익은 달력에서 보고 있는 달의 1일부터 마지막 날까지 같은 집계 기준으로 합산한다.
