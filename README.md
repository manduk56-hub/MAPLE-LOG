# 메이플로그

메이플스토리 보스 일기장. 캐릭터, 파티원, 날짜, 보스, 획득 아이템 이름과 당시 가격을 기록합니다.

## 실행

개발 중에는 바탕화면 바로가기로 현재 프로젝트 소스를 실행합니다. 코드 수정 후 앱을 다시 열면 반영됩니다. 일반 수정 때는 버전을 올리거나 설치 파일을 만들지 않습니다. 아래 설치 파일 빌드는 다른 사람에게 배포할 때만 진행합니다.


### Windows 프로그램

`npm run build`로 생성한 `release/Maplelog-Setup-<버전>.exe`를 실행하면 설치 위치를 선택하고 바탕화면·시작 메뉴 바로가기를 만들 수 있습니다. 설치 후 **메이플로그**를 더블 클릭하면 독립 창으로 실행됩니다. Node.js나 별도 서버가 필요하지 않습니다.

설치 전 바로 사용하려면 `release/win-unpacked/메이플로그.exe`를 실행합니다. 해당 폴더의 나머지 파일도 함께 보관해야 합니다.

설치 없이 다른 사람에게 전달하려면 `npm run build:dir` 후 `scripts/package-portable.ps1 -OutputPath 원하는경로\메이플로그.zip`을 실행합니다. 받는 사람은 ZIP 전체를 압축 해제하고 `메이플로그.exe`로 실행합니다. `바로가기 만들기.cmd`는 바탕화면에 **메이플로그** 바로가기를 만들고 성공·실패를 안내합니다. 같은 이름의 바로가기는 새 실행 경로로 갱신됩니다. 배포 ZIP에는 개인 기록과 백업을 포함하지 않습니다.

프로그램 기록은 `%APPDATA%/Maplelog`에 자동 저장됩니다. 창을 닫고 다시 실행해도 기록과 창 크기를 유지합니다. 이전 웹 버전에서 기록했다면 웹 화면에서 백업을 내려받고 프로그램에서 **백업 복원**으로 가져오세요.

### 개발 실행

`npm install` 후 `npm start`로 독립 창을 실행합니다. 웹 미리보기는 `npm run dev` 실행 후 http://127.0.0.1:5173 에서 확인합니다.

`npm run build`로 Windows 설치 파일을, `npm run build:dir`로 설치 없는 실행 폴더를 생성합니다.

## 기능

- 월별 달력, 날짜별 기록과 월간 요약
- 달력의 연도·월을 클릭해 연도를 입력하고 월을 선택하면 즉시 이동
- 일기 추가·수정·삭제, 검색과 정렬
- 아이템 총액과 분배 인원에 따른 1인당 금액 (나머지 메소는 버림)
- 모든 시스템의 JSON 공통 백업과 복원 (파일에 포함된 시스템만 교체)
- PC와 모바일 화면 지원
- 새 설치 파일로 보스·난이도·아이템 목록 갱신, 기존 기록 유지

새 콘텐츠는 목록을 수정한 새 설치 파일로 배포합니다. 사용자는 앱을 닫고 기존 프로그램 위에 새 버전을 설치하면 같은 기록을 계속 사용할 수 있습니다. 기록은 설치 폴더가 아닌 Windows 사용자별 `%APPDATA%/Maplelog`에 보관합니다. 다른 PC나 계정으로 옮길 때는 백업을 이용하세요. 자세한 절차는 [업데이트와 기록 보존 안내](docs/content-updates.md)를 참고하세요.

프로그램과 웹 브라우저는 별도 저장 공간을 사용합니다. 웹 기록은 접속한 브라우저의 localStorage에 저장되며, 브라우저 데이터 삭제 시 지워지므로 백업을 보관해주세요. 가격은 사용자가 입력한 당시 가격이며 실제 판매 수익이나 현재 시세와 연동되지 않습니다. 아이템 없는 날은 입력 행을 지우고 저장할 수 있습니다.

검사: `npm run check`

보스·소비 기록 목록은 기본 5개씩 표시하며 10개씩 보기와 전체 보기를 선택할 수 있습니다. 목록 위·아래에서 페이지를 이동할 수 있고, 검색·분류·날짜·정렬을 바꾸면 첫 페이지로 돌아갑니다. 표시 개수와 관계없이 요약·정산은 해당 기간의 전체 기록으로 계산합니다.

왼쪽 **메소 정산**에서 일·주·월·전체 기간을 선택해 정산을 보고 기준 날짜를 변경할 수 있습니다. 각 기간의 왼쪽에는 보스·아이템 이미지와 획득 수, 소비 순위를 배치하고 오른쪽에는 메소 이미지와 수익·소비·순수익을 세로로 표시합니다. 주간은 목요일~수요일이며, 모든 캐릭터의 잡은 보스 수(일기당 1회), 획득 아이템 항목 수, 분배 후 보스 수익과 소비 일기 수익, 총소비량, 순수익, 소비 분류별 지출 1~3위를 합산합니다. 전체 기간은 날짜 제한 없이 모든 기록을 집계합니다.

소비 항목별로 사용액을 직접 입력하거나 시작·종료 메소의 차이로 계산할 수 있습니다. 잔액 계산의 원본 값과 입력 방식을 저장하므로 일기 수정과 백업 복원 후에도 유지됩니다. 잠재능력·에디셔널 잠재능력 재설정 비용 자체를 자동 산출하는 기능은 제공하지 않습니다.

왼쪽 **나의 모험 기록** 메뉴에서 보스 일기와 소비 일기를 전환합니다. 소비 일기는 **소비 정산**부터 시작하며 일·주·월 소비액, 소비 달력, 날짜별 메모장을 제공합니다. 아이템 구매·스타포스·주문서·추가옵션·잠재능력·에디셔널 잠재능력·익셉셔널·소울웨폰·흔적복구·특수 스킬·반지 연마·소모품·기타로 분류하고, 보스 일기처럼 한 일기에 여러 항목과 금액을 입력할 수 있습니다. 날짜별 메모는 소비 기록 없이도 저장할 수 있습니다. 기록 검색·분류 필터·정렬·수정·삭제를 지원하고 일기와 메모 모두 공통 백업에 포함됩니다. 소비 금액은 사용자가 입력한 메소이며 보스 수익에서 자동 차감하지 않습니다.

수량 입력 없이 아이템별 당시 가격을 기록합니다. 이전 버전의 수량이 있는 기록·백업은 수량 × 개당 가격을 해당 아이템의 가격으로 변환하여 기존 총액을 유지합니다. 새 백업은 여러 시스템을 담는 버전 3 형식이며, 이전 버전 1·2 백업도 복원할 수 있습니다. 예전 보스 일기 백업을 복원해도 다른 시스템은 유지됩니다. 새 메뉴 개발 방법은 [시스템 공통 백업](docs/shared-backups.md)을 참고하세요.

화면은 메이플 옥션과 게임 설치 파일의 아이템 정보창 설정을 참고합니다. 읽기 쉬운 Noto Sans KR 글꼴을 화면과 입력창에 적용하고 글자 그림자를 제거했으며, 흰색·연두색·청록색 강조를 유지합니다. 글꼴 라이선스는 `assets/fonts/NotoSansKR-OFL.txt`와 `assets/fonts/LICENSE.txt`에 있습니다. 게임 파일에서 확인한 경로와 설정은 `docs/maple-ui-reference.md`에 기록했습니다.

금액은 조·억·만·나머지 메소까지 표시하며 축약하거나 반올림하지 않습니다. 일별·주별 수익은 선택한 날짜(기본 오늘)를 기준으로 표시합니다. 주간 범위는 목요일부터 수요일까지이며 월·연도 경계를 포함합니다. 기본 기준은 분배 후 내 몫이고 아이템 총액으로 전환할 수 있습니다.
